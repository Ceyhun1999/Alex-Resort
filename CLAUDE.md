# ALEX Resort & Spa Apartments — правила проекта

Сайт строящегося комплекса апартаментов в Гагре (Jeywa Studio). Статический фронтенд: HTML, CSS, ES-модули, GSAP. Структура описана в `README.md`, исходники клиента — в `materials_for_website/` (не изменять).

## Anti-AI Design Aesthetic

Действует глобальное правило из `~/.claude/CLAUDE.md` (пункты 7–9), для этого сайта оно обязательно:

- Не добавляй декоративные горизонтальные линии у заголовков и надзаголовков, разреженный капс с большим letter-spacing, однотипные карточки, бессмысленные градиенты, повторяющиеся композиции секций, шаблонный hero и украшения без смысла.
- Оформление выводи из бренда ALEX: брендбук (Lora + Montserrat; `#233c57`, `#1f7396`, `#51a1b4`, `#b59779`, `#f2ebe1`), фирменная волна из логотипа, реальная съёмка объекта и моря.
- Перед завершением любой визуальной правки проведи Anti-AI Design Review по скриншотам всех затронутых секций и устрани найденные шаблоны.
